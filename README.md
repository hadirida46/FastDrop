# 🚀 Fast Drop — Delivery Web App

**Fast Drop** is a simple yet functional delivery web application built with **HTML**, **CSS**, **Bootstrap**, **JavaScript**, **Leaflet.js**, and **PHP**.  
It allows users to create, manage, and track delivery orders with real-time map coordinates.

---

## 📌 Features

- **User Authentication** — Sign up, log in, and log out securely.
- **Order Management** — Create, edit, delete, and monitor orders.
- **Location Picker** — Select source and destination by location name or map coordinates (Leaflet.js).
- **Dashboard** — View all your active and completed orders.
- **Responsive Design** — Works well on mobile and desktop (Bootstrap-based).

---

## 🛠️ Tech Stack

- **Frontend**:
  - HTML5
  - CSS3
  - Bootstrap
  - JavaScript
  - Leaflet.js (Interactive Maps)
- **Backend**:
  - PHP
- **Database**:
  - MySQL
